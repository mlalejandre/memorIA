# experiment/

Historical outputs from past evaluation runs (`baseline_auto.json`, `eval_auto.json`).
They were generated from a private memory and have no generator script in this repository;
entries derived from personal facts were removed. Use `benchmarks/prueba.py` for reproducible measurements.

`baseline_v0.3.json` is the frozen baseline of release 0.3.0a1 (suite `escala`, 100,108 facts, real servers).
Compare any future change against it.
